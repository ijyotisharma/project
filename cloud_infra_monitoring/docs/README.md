Cloud Infrastructure Monitoring & Auto-Remediation
🚀 End-to-End Cloud Infrastructure Monitoring and Automated Incident Response System

📌 Project Overview
This project simulates a real-world Site Reliability Engineering (SRE) setup by deploying an AWS EKS cluster with observability, auto-remediation, and CI/CD.
It includes:
✅ AWS EKS Cluster setup with Terraform
✅ Prometheus & Grafana for monitoring
✅ Auto-remediation scripts for self-healing services
✅ CI/CD pipeline with Jenkins & GitHub Actions
✅ PagerDuty integration for real-time incident response
